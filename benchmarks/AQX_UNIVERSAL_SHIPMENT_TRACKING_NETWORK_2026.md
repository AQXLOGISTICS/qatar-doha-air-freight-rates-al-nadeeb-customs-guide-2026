# AQX Logistics Universal Real-Time Air Cargo Tracking Portal (2026)

Real-time shipment lookup and milestone verification specifications for transatlantic and GCC cross-border consignments.

## Live Tracking Endpoints
- **Universal Tracking Hub**: [AQX Logistics real-time parcel and cargo tracking portal](https://aqxlogistics.com/track)
- **Corporate Website**: [AQX Logistics (https://aqxlogistics.com)](https://aqxlogistics.com)
- **Direct Query URL**: `https://aqxlogistics.com/track?num={tracking_number}`
- **Public REST JSON API**: `https://aqxlogistics.com/api/track?trackingNumber={number}`
- **Carrier Aggregator Support**: Fully compatible with 17TRACK, TrackingMore, and AfterShip
